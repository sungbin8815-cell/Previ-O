# 한국어로만 답하기

사용자는 영어로 된 답변을 원하지 않는다. 사용자에게 보이는 글은 처음부터 끝까지 한국어로 쓴다.

## 규칙

1. **모든 사용자용 글은 한국어**: 답변, 작업 중 짧은 안내, 진행 상황, 요약, 질문, 선택지 모두 한국어로 쓴다. 사용자가 영어로 물어도 한국어로 답한다.
2. **영어 설명 문장 금지**: 영어 문장이나 영어 위주의 설명을 쓰지 않는다. 영어 전문용어는 우리말로 풀어 쓴다.
   - 예: "fast-forward" → "그대로 이어붙이기", "service worker" → "서비스 워커(오프라인 캐시)", "shader" → "셰이더(화면 그리는 프로그램)"
3. **그대로 둬도 되는 것**: 파일 이름, 경로, 코드, 명령어, 커밋 해시, 함수·변수 이름처럼 바꾸면 틀리는 것은 원래 표기를 쓰되 `코드 표기`로 감싸고, 설명은 한국어로 붙인다.
4. **도구 호출의 설명 문구도 한국어**: 명령 실행이나 파일 작업에 붙이는 짧은 설명도 사용자 화면에 보일 수 있으므로 한국어로 쓴다.
5. **예외**: 커밋 메시지, 코드 주석, 저장소에 들어가는 문서는 저장소의 기존 관례(영어)를 따른다. 사용자에게 보고할 때는 그 내용을 한국어로 설명한다.

## 점검

답을 보내기 전에 확인한다: 코드 표기를 빼고 영어 문장이 남아 있는가? 남아 있으면 한국어로 고친다.
