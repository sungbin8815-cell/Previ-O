# 사용자가 정한 디자인 결정 (PREVIO)

팀도 팀장도 뒤집지 않는다. 바꾸자는 의견은 "사용자께 드리는 제안"으로만 올린다. 사용자가 새로 정하거나 바꾸면
진행자가 이 파일을 고친다.

## 앱과 사용자

- PREVIO는 촬영 전 장면을 미리 짜 보는 프리비즈·콘티 도구다. 간편 모드는 처음 쓰는 사람, 프로 모드는 감독·촬영감독·조감독용이다.
- 화면에 보이는 글은 모두 한국어다.
- 휴대폰 가로 화면이 기본이다. 세로로 들면 돌려 달라고 안내한다. 태블릿과 컴퓨터도 지원한다.

## 분위기와 색 (2026-11-28 사용자 결정: 「촬영장 모니터 카트」)

- 예전 렌즈 콘셉트(그래파이트·라임·실버)와 애플 시안은 버렸다. 지금 방향은 촬영장 모니터 카트다.
- 그림은 검은 칸 위에만(무대·모니터·탑·샷 띠), 도구는 알루미늄 회색 몸체(`#D4D5D7`) 위에 검은 글씨로 둔다.
- 빨강(탤리 `#E3241B`)은 "지금 살아 있는 것"에만 쓴다: 고른 샷, 재생 머리, 녹화. 고른 것은 회색 위에선 검정, 검은 칸 안에선 흰색.
- 둥근 판·알약 버튼·형광 강조색·그림자를 쓰지 않는다. 채운 버튼은 한 화면에 하나.
- "AI 티", "템플릿 티", 네모 박스 늘어놓기를 싫어한다.
- Astryx 테마는 두 벌이다: `cart`(회색 몸체, 밝은 쪽)와 `well`(검은 칸, 어두운 쪽). 무대 위 부품은 `well`, 나머지는 `cart`.

## 글꼴

- 글은 SUIT, 숫자와 코드는 Archivo Narrow, 로고 PREVIO는 넓은 Archivo.

## 조작

- 화각, 조리개처럼 정해진 숫자 중에서 고르는 값은 눈금자로 한다.
- 딤처럼 0~100인 값은 다이얼로 한다. 원을 그리며 돌리는 방향대로 값이 따라가야 한다.
- 전체적으로 기계적인 느낌을 살린다.

## 부품과 기능

- 화면 부품은 Astryx 부품을 쓴다. `ui/`의 연결 장치가 앱의 기존 버튼과 입력칸 자리에 그려 넣는다.
- 기능을 건드리면 반드시 보고한다.
- 작동하지 않는 화면 요소는 두지 않는다.
- 캐릭터 꾸미기(얼굴, 옷 고르기) 화면은 없앴다. 다시 넣지 않는다.

## 화면 배치 (2026-11-26 디자인 팀 회의 뒤 사용자 결정)

- 컴퓨터는 3D 프로그램(C4D)처럼 화면을 여러 개 띄운다: 1화면(전환), 2화면(모니터 + 3D/탑), 3화면(모니터 + 3D + 탑). 기본은 2화면.
- 휴대폰은 한 번에 한 화면. 컴퓨터와 배치가 다르다: 왼쪽 손잡이에 카메라 도구, 오른쪽 손잡이에 모든 패널·스토리보드·더보기.
- 컴퓨터에서 패널이 열려 있으면 왼쪽 도구 줄은 숨긴다(패널의 탭이 대신한다).
- 컴퓨터는 설정 패널을 처음부터 열어 둔다. 휴대폰은 닫힌 채 시작한다.
- 녹화 빨간 테두리는 전체 재생 중에만 켠다.
- 판독값 숫자는 크게 키우지 않는다(15px). 글자 최소 12px.
- 필요하면 기능을 고쳐도 된다. 바꾼 점은 보고한다.

## 아직 정하지 않은 것

- Astryx 레이아웃 부품으로 화면 틀 전체를 다시 짜는 시안(`canvas-editor` 템플릿 틀)을 보여 드렸고, 아직 결정 전이다.
