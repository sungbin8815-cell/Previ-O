# 요청 원문 (2026-11-28, 사용자)

> 아래는 사용자가 보낸 명세를 그대로 옮긴 것이다. 계획과 설계는 이 원문을 근거로 한다.

PREVIO — Professional Software UI/UX Redesign
Final Implementation Specification for Claude Code
기존 PREVIO 프로젝트를 전문적인 3D 프리비즈 소프트웨어 수준으로 리디자인해줘.
이번 작업은 단순한 스타일 변경이 아니야. 기존 애플리케이션의 기능과 데이터 구조를 유지하면서 전체 UI 아키텍처와 사용자 경험을 개선하는 작업이야.
가장 중요한 목표는 다음과 같아.
Cinema 4D의 전문적인 작업 구조 + Apple의 직관적인 인터랙션 + 촬영감독을 위한 간결한 도구 구성.
AI가 생성한 듯한 일반적인 대시보드나 SaaS 템플릿 디자인은 사용하지 마.

## 1. 작업 전 필수 분석
코드를 수정하기 전에 현재 프로젝트 전체를 분석해줘.
확인할 사항:
* 프로젝트 디렉터리 구조
* 사용 중인 프레임워크 및 라이브러리
* 페이지 및 컴포넌트 구조
* 3D 렌더링 엔진
* 카메라 및 렌즈 계산 로직
* 초점 및 노출 관련 로직
* 조명 및 세트 시스템
* 스토리보드 및 샷 관리
* 프로젝트 저장 및 불러오기
* 상태 관리 및 데이터 구조
* 현재 반응형 레이아웃

기존 기능이 어떤 컴포넌트와 상태에 연결되어 있는지 파악한 다음 작업해줘.
기존 구조를 무작정 삭제하거나 전체 코드를 새로 작성하지 마.
먼저 리디자인 계획을 세우고 기존 기능에 영향을 주지 않는 범위에서 수정해줘.

디자인 레퍼런스

이들의 디자인을 그대로 복제하지 말고 PREVIO의 목적에 맞게 재구성해줘.

디자인 원칙
* 기능 중심의 레이아웃
* 일관된 패널 구조
* 정확한 정렬과 여백
* 명확한 정보 위계
* 불필요한 장식 최소화

* 실제 전문 소프트웨어 같은 완성도

금지 사항
다음과 같은 디자인은 사용하지 마.
* 일반적인 AI SaaS 대시보드
* 모든 요소를 둥근 카드로 감싸는 디자인

* 의미 없는 장식용 아이콘
* 지나치게 큰 제목과 버튼

## 3. PC 레이아웃 — Fixed Workspace
PC는 전문 데스크톱 소프트웨어로 설계해줘.
패널은 고정형 구조를 사용해.
사용자가 패널을 임의로 이동하거나 도킹할 수 있는 자유 배치 기능은 구현하지 마.
대신 패널의 너비와 높이를 조절하거나 접고 펼치는 기능은 지원해줘.

기본 화면 구조
상단:
* 프로젝트명
* 프로젝트 저장 상태
* Undo
* Redo
* 뷰포트 레이아웃 전환
* 내보내기

좌측:
* 도구 팔레트

중앙:
* 3D 뷰포트

우측:
* 속성 인스펙터

하단:
* 타임라인 및 샷 관리

각 영역은 명확하게 구분해줘.
중앙 뷰포트가 가장 중요한 영역이므로 가능한 넓은 공간을 확보해줘.

### 3-1. 상단 툴바
상단 툴바는 항상 동일한 위치에 유지해줘.
다음 기능을 배치해줘.
* PREVIO 프로젝트명
* 저장 상태
* 실행 취소
* 다시 실행
* 뷰포트 레이아웃 선택
* 내보내기

자주 사용하지 않는 기능을 상단에 무리하게 배치하지 마.
아이콘과 텍스트를 적절히 조합하고 마우스 오버 시 기능 설명을 표시해줘.

### 3-2. 좌측 도구 팔레트
Cinema 4D처럼 세로형 도구 팔레트를 만들어줘.
기존 프로젝트에 존재하는 기능을 분석해서 분류해줘.
기본적인 분류 방향:
* 선택
* 이동
* 회전
* 스케일
* 카메라
* 조명
* 세트
* 오브젝트
* 측정
* 주석

실제 기존 기능에 존재하지 않는 도구는 임의로 만들어 넣지 마.
도구는 아이콘과 명확한 이름으로 구분해줘.
도구 그룹을 접거나 펼칠 수 있도록 해줘.
자주 사용하는 기능은 즐겨찾기에 등록할 수 있도록 설계해줘.

### 3-3. 뷰포트 레이아웃
이번 프로젝트에서 가장 중요한 기능 중 하나야.
Cinema 4D와 같은 방식으로 다음 두 가지 레이아웃을 구현해줘.

A. Single View
* 하나의 Perspective 뷰포트
* 중앙 작업 공간을 최대한 활용
* 카메라 구도 확인에 최적화
* 전체 화면처럼 넓은 작업 공간 제공

B. Three View
3개의 뷰포트를 동시에 표시해줘.
배치는 다음과 같이 해줘.
* 왼쪽: Perspective
* 오른쪽 상단: Top
* 오른쪽 하단: Front

Perspective가 가장 넓은 공간을 차지해야 해.
Top과 Front는 보조 뷰포트로 배치해줘.

뷰포트 필수 기능
1. 상단 툴바에서 Single / Three View 전환
2. 각 뷰포트의 경계선 드래그를 통한 크기 조절
3. 뷰포트 더블클릭으로 개별 최대화
4. 다시 더블클릭하면 기존 레이아웃으로 복귀
5. 활성 뷰포트 표시
6. 각 뷰포트의 시점 선택
7. 각 뷰포트별 그리드 및 표시 옵션
8. 뷰포트 전환 시 기존 카메라 상태 유지

반드시 지켜야 하는 기술 조건
세 개의 뷰포트는 각각 별도의 3D 씬을 생성하는 것이 아니야.
반드시 동일한 씬 데이터와 오브젝트 상태를 공유해야 해.
각 뷰포트는 동일한 3D 월드에 서로 다른 시점의 카메라를 연결하는 구조로 구현해줘.
Perspective, Top, Front는 각각 독립적인 시점을 가져야 해.
한 뷰포트에서 오브젝트를 이동하거나 회전하면 다른 뷰포트에도 즉시 반영되어야 해.
기존 3D 엔진과 렌더링 구조를 최대한 재사용해줘.
기존 엔진이 여러 뷰포트 렌더링을 지원하지 않는다면 무리하게 새로운 엔진을 도입하지 말고 현재 기술 스택에 적합한 방법을 먼저 검토해줘.

### 3-4. 우측 속성 인스펙터
우측 패널은 선택한 대상에 따라 자동으로 변경되는 구조로 만들어줘.
카메라 선택:
* 렌즈
* 초점
* 노출
* 거리
* 센서

조명 선택:
* 광원 종류
* 밝기
* 색온도
* 위치
* 방향

세트 및 오브젝트 선택:
* 위치
* 회전
* 크기
* 기존에 지원하는 세부 설정

기존에 존재하는 속성만 노출해줘.
각 항목은 명확한 제목과 값으로 구성하고 불필요한 장식을 제거해줘.

### 3-5. 하단 타임라인
기존 스토리보드 및 샷 관리 기능을 분석해 현재 구조를 유지하면서 정돈해줘.
* 샷 목록
* 샷 순서
* 프레임 또는 시간 정보
* 타임라인 조작
* 기존 스토리보드 연결

타임라인은 기본적으로 하단에 고정하되 필요하지 않을 때 접을 수 있도록 해줘.

## 4. 도구 검색 시스템
전문 소프트웨어처럼 도구를 빠르게 찾을 수 있도록 해줘.
Cinema 4D Commander와 유사한 방식으로 구현해줘.
* Mac: Cmd + K
* Windows: Ctrl + K

검색 기능:
* 도구 이름 검색
* 기능 이름 검색
* 기존 메뉴 검색
* 최근 사용 도구 표시
* 즐겨찾기 표시
* 검색 결과 클릭 시 해당 도구 실행

검색창은 화면 중앙에 간결하게 표시해줘.
검색 결과는 기능별로 분류하고 현재 사용 가능한 기능만 노출해줘.

## 5. 모바일 UI — Mobile Workspace
모바일은 PC의 축소판이 아니야.
PC와 기능 및 데이터는 공유하지만 레이아웃은 별도로 설계해줘.
모바일에서는 간편함이 가장 중요해.

기본 구조
상단:
* 프로젝트명
* Undo / Redo
* 저장
* 내보내기

중앙:
* 단일 3D 뷰포트

하단:
* 카메라
* 조명
* 세트
* 기존 주요 기능

모바일 뷰포트
모바일에서는 기본적으로 단일 뷰만 지원해줘.
PC의 Three View를 억지로 모바일에 적용하지 마.
3D 뷰포트를 최대한 넓게 보여줘.

모바일 속성 패널
설정 버튼을 누르면 하단 시트 형태로 표시해줘.
예시:
카메라:
* 렌즈
* 초점
* 노출
* 거리
* 센서

필요한 항목을 선택하면 해당 설정을 표시해줘.
한 번에 너무 많은 설정을 노출하지 말고 그룹별로 구분해줘.
하단 시트는 닫거나 확장할 수 있어야 해.
설정을 변경하면 3D 뷰포트에 즉시 반영되어야 해.

모바일 조작
* 충분한 터치 영역
* 쉬운 슬라이더 조작
* 숫자 직접 입력 지원
* 간결한 메뉴 구조
* 불필요한 화면 이동 최소화

PC의 기능을 모바일에 전부 노출하려 하지 마.

## 6. 홈 화면 리디자인
홈 화면은 프로젝트 관리에 집중해줘.
구성:
1. PREVIO 로고 및 설정
2. 새 프로젝트 만들기
3. 프로젝트 불러오기
4. 최근 프로젝트 목록
5. 프로젝트 템플릿
6. 튜토리얼 및 포커스 연습

최근 프로젝트는 썸네일과 프로젝트명을 중심으로 표시해줘.
기존의 과도하게 큰 카드 디자인을 제거하고 간결한 목록 또는 그리드로 구성해줘.

- PHASE 1. 기존 코드 분석: 전체 프로젝트 구조 확인, 기존 기능 및 상태 관리 분석, 현재 UI 구조 파악, 위험 요소 확인
- PHASE 2. 디자인 시스템: 색상 및 타이포그래피, 버튼 및 입력창, 탭 및 인스펙터, 공통 UI 컴포넌트
- PHASE 3. PC 작업 환경: 고정형 레이아웃, 좌측 도구 팔레트, 중앙 뷰포트, 우측 인스펙터, 하단 타임라인
- PHASE 4. 뷰포트: Single View, Three View, 독립적인 시점, 동일 씬 공유, 크기 조절, 최대화 및 복구
- PHASE 5. 모바일: 단일 뷰포트, 하단 내비게이션, 속성 시트, 터치 최적화
- PHASE 6. 홈 화면: 프로젝트 관리, 최근 프로젝트, 템플릿
- PHASE 7. 검증: 기존 프로젝트 불러오기, 저장 및 재접속, 카메라 조작, 렌즈 변경, 초점 변경, 조명 변경, 세트 변경, 스토리보드 및 샷 관리, Single / Three View 전환, PC / 모바일 반응형 확인

각 단계가 완료되면 실제 작동 여부를 확인해줘.
문제가 발생하면 기능을 제거하는 방식으로 해결하지 말고 원인을 찾아 수정해줘.

## 최종 목표
PREVIO는 일반적인 AI 생성 웹앱처럼 보여서는 안 돼.
Cinema 4D처럼 전문적인 작업 구조를 가지되, 촬영 설계라는 목적에 맞게 복잡한 기능을 정리한 소프트웨어여야 해.
PC에서는 전문적인 작업 환경을 제공하고 모바일에서는 빠르고 간편한 촬영 설계를 제공해줘.
기능은 깊게, 인터페이스는 단순하게, 작업 흐름은 직관적으로.
이것이 PREVIO의 최종 디자인 방향이야.

## 추가 요청 (같은 메시지)
추가로 간편모드 사용자는 촬영에 대해 잘 모르지만 에이아이 영상을 만드는 사람을 위한 것이고 프로는 실제 촬영 때 어떻게 찍을지 기획하는 사람 용이야. 간편모드에서 에이아이프롬프트를 실사가 아닌 기본으로 바꿔주고 사진을 찍어서 구도를 잡을 수 있게 해줘. 또한 간편모드에서 샷사이즈나 앵글을 클릭으로 바로바로 짤 수 있게 해줘. 그리고 기능 요소들이나 배치, 그룹으로 묶여있는건 너가 판단해서 어떻게 묶고 어떻게 따로 두고 어떻게 배치할지 정해줘. 이 내용을 한 번에 명령하긴 빡세니까 너가 정리해줘. 슈퍼파워 스킬을 사용해서 정리하자.
