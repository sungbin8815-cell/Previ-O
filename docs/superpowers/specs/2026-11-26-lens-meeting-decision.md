# 통합안: 앱 배치 전면 개편 (최종)

## 팀장이 코드에서 직접 확인한 사실 (판정 근거)
- 판독값 칩 `.chipi`는 `pointer-events:none`이라 누를 수 없다(`index.html:157`).
  - 버튼은 노출 경고(`button.chipi.bad.act[data-autoexp]`, `:6857`) 하나다.
  - 버튼이 아닌 경고 "초점 불가 · 최소 …"가 하나 더 있다(`:6856`).
- `openPane()`(`:8121`)은 초점을 옮기지 않는다.
- 휴대폰 가로의 서랍은 덮개가 아니다. `.app.docked`(`:912-914`)가 서랍을 3D 옆 칸으로 붙인다. 주석: "instead of covering the picture".
- `syncBars()`(`:6410-6416`)에서 `#camBar`는 놓기 · 짓기 · 크레인 · 모니터 보기 · 인물 이동 중에 숨는다. `#objBar`는 모니터 보기와 놓기 중에 숨는다.
- `#movePad`는 컴퓨터(마우스)에서 CSS가 늘 숨긴다(`:920`). 가상캠 `#gVcam`은 터치에서만 보인다(`:857`). 그래서 모니터 가이드는 컴퓨터 2개, 휴대폰 3개다.
- 모니터 아래 판독 `.hud.b`(`#hudL` · `#monInfo` · `#hudB`, `:1712`)는 DOM 글이다. 캔버스에 그린 글이 아니라서 옮길 수 있다.
- 튜토리얼 단계 `:8216`, `:8225`는 `#hudTop`을 가리킨다.
- "「＋ 샷」"은 `:8212`, `:8224`, `:8238`, `:8249`, `:9321`에 나온다.
- `#tl`을 누르면 샷을 고른다(`:7599`). 길이 조절 기능은 없다.
- `#sceneMeta` 글은 보드(`:7635`)와 인쇄(`:8018`, `:8029`)가 함께 쓴다.

## 최종 변경 목록 (구현 순서)

### 0. 지킬 것
- 기존 요소의 id · class · data 속성은 지우거나 이름을 바꾸지 않는다. 숨길 때는 `hidden` 또는 화면에서만 숨기는 클래스를 쓴다.
- 옮긴 뒤에는 C/R/L/T/H · B · P · N · 1/2/3, 보기 전환, 편집/보드, 샷 끌어 순서 바꾸기, 내보내기 메뉴를 다시 시험한다.
- `ui/`를 고치면 `cd ui && npm run build`로 `ui/dist/`를 다시 만들어 함께 커밋한다.

### 1. 토큰 (`index.html:30-33`의 `:root` 정의 + 렌즈 테마) [디자인 3라운드]
- **값 바꿈**: `--muted #7E8187 → #8B8E94`.
- **새 토큰**:
  - `--line-strong #686B70`: 입력칸 · 드롭다운 · 슬라이더 바탕선, 클립 · 젤 칸 · 미리보기 테두리.
  - `--danger-ink #E5675C`: 지우는 글과 아이콘.
  - `--sh-float: 0 0 0 1px var(--line), 0 8px 24px` 검정 45%.
- **그대로 쓰는 토큰과 쓰는 곳**:
  - `--paper #0D0E0F`: 캔버스 둘레, 모니터 틀 밖.
  - `--sheet #151618`: 붙은 면 전부.
  - `--raise #1C1D20`: 클립, 입력칸, 켜진 칸, 알림, 키.
  - `--line #2A2C30`: 면 경계. 이 위에는 글자를 두지 않는다.
  - `--silver #AEB3BA`: 판독 세로선 1×16, 눈금.
  - `--ink #ECEDEE`: 값, 제목, 켜진 글, 초점 표시.
  - `--ink2 #B6B8BC`: 12px 글 전부, 꺼진 탭·칸.
  - `--accent #C9DD4F`, `--accent-ink #121309`, `--caution #E3B341`.
  - `--rec #E5483A`: 녹화 테두리에만.
- **초점 표시**: `outline:2px solid var(--ink); outline-offset:2px`. 화면 끝에 붙은 칸(도크 칸, 위 띠 탭, 타임라인 머리 양 끝 버튼)은 `.app{overflow:hidden}`에 잘리므로 `outline-offset:-2px`.
- **렌즈 테마**: `npx @astryxdesign/cli@0.7.17 experimental theme editor how "…"`로 보조 글자색 #8B8E94, 경계 #686B70, 모서리 6/4, 초점 고리 2px #ECEDEE의 `editor set lens … --on <part>` 줄을 받아 실행한다. 그다음 `editor show lens --png`로 사진을 열어 확인한다. `accent`와 `font`는 바꾸지 않는다.
- **글자**:
  - Plex Sans KR: 12/400 `--ink2`, 13/400·600, 15/600.
  - Barlow Condensed: 13/500, 15/500·600, 20/500, 28/600.
  - 숫자는 `tabular-nums`. 고정폭 글꼴과 자간 대문자는 없앤다. 글자 바닥은 12.

## 기능에 닿는 점
- **사용자 확인 필요 1**: 서랍을 여닫을 때 초점을 옮긴다(9번).
  - `openPane()`에 JS를 더한다.
  - 숨은 `role="status"` 칸을 새로 만든다.
- **사용자 확인 필요 2**: 튜토리얼 문구와 대상이 바뀐다(12번).
  - 휴대폰 단계의 대상이 `#navMore`에서 `#rail`로 바뀐다.
  - 퀘스트 네 곳의 버튼 이름이 바뀐다.
- **사용자 확인 필요 3**: 폭이 좁을 때 자세 버튼이 "자세 ▾" 목록으로 접힌다(7번). 그 경우에만 한 번 더 누른다.
  - 1224 폭의 3D 보기에서는 접히지 않는다. 904 폭(인스펙터 열림)이나 탑 보기에서만 접힌다.
- **사용자 확인 필요 4(시안으로 확인)**: 도구 줄이 왼쪽에서 오른쪽 끝으로 옮겨 간다. 휴대폰에서는 장비 · 조명 · 세트 · 샷이 더보기에서 도크로 나온다. 단축키와 여닫기는 그대로다.
- **보고 (동작 그대로, 그리는 방식이나 글만 바뀜)**:
  - `#stageInfo` 그리는 글(`:6855-6857`)이 칸과 한글 이름으로 바뀐다. `#hudTop`과 `.hud.b`가 띠로 옮겨 간다.
  - 위 띠 넘침 숨김과 아래 띠 넘침 처리에 `ResizeObserver`를 쓴다.
  - `syncTimeline()`의 구간이 px 폭으로 바뀌고, 숫자는 5초마다 고정된다.
  - `tlHead()`에 px 계산(`--phx`)이 붙는다. `#strip` 스크롤 리스너 한 줄이 더해진다. `thumbSize()`가 100×56 상자 기준이 된다.
  - DOM 순서를 옮긴다(3번). 옮긴 뒤 기능을 시험한다.
  - 알림 · `cardMeta()` · 판독 글이 바뀐다(12번). 알림 동작 버튼 이름이 "되돌리기"에서 "실행 취소"로 바뀐다(같은 `undo`).
  - 휴대폰:
    - 인스펙터가 샷 줄 위까지만 붙는다.
    - 인스펙터가 열린 동안이나 붙는 띠가 있는 동안 미리보기가 숨거나 올라간다.
    - 경고가 뜨면 상단 바 판독 값이 숨는다.
    - 이동 키 배치가 십자에서 2×3으로 바뀐다(같은 키, 함께 누르기 유지).
  - 반투명 판(`.glass`, `opacity:.8`)이 모두 단색이 된다.
  - "+ 샷"이 라임 채움에서 보조 버튼으로 바뀐다.
- **숨기지만 지우지 않는 요소**: `#dTabs`, `#addCard`, 샷 줄 머리의 "SHOTS / 1컷 · 0:03", "프리비즈 스튜디오", `.tl-seg` 안의 글(화면에서만), 휴대폰 `#moreSheet`의 도구 버튼, 모니터 보기의 FPS · S01.
- **바뀌지 않는 것**: 서랍 기본 상태(닫힘), 보기 전환, 편집/보드, 모든 단축키, 내보내기 메뉴, 샷 끌기, 누르는 동작들.

- 지난번 Astryx `canvas-editor` 시안은 따르지 않기를 권한다(다섯 자리 모두 같은 의견). 이 통합안이 그 시안을 대신한다.

## 사용자 결정 (팀 결정 뒤, 최우선)
- 기능에 닿는 네 가지(초점 이동, 튜토리얼 문구, 자세 접기, 도구 줄 오른쪽)는 모두 진행한다. 기능은 필요한 만큼 고친다.
- 컴퓨터는 설정 패널을 처음부터 열어 둔다(카메라). 휴대폰은 닫힌 채 시작한다.
- 모니터의 빨간 녹화 테두리는 전체 재생 중에만 켠다. 평소에는 1px `--line-strong`.
- Esc로 패널 닫기, F6으로 영역 이동 단축키를 더한다.
- 판독값 글자는 20 → 15(Barlow 15/500). 글자 바닥 12는 그대로.
